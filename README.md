# Solar Panel Defect Detection

## Overview

This project detects and classifies defects on solar panels using a deep learning model. Given an image of a solar panel, the model predicts which of six conditions the panel is in. The six classes are Bird-drop, Clean, Dusty, Electrical-damage, Physical-Damage and Snow-Covered.

The dataset has 885 images across these six classes. Because the dataset is small and imbalanced, I used MobileNetV2 with ImageNet weights as the base model rather than training a CNN from scratch. This gave significantly better results.

## Dataset

| Class | Images |
|-------|--------|
| Bird-drop | 207 |
| Clean | 193 |
| Dusty | 190 |
| Electrical-damage | 103 |
| Physical-Damage | 69 |
| Snow-Covered | 123 |
| Total | 885 |

Physical-Damage and Electrical-damage are underrepresented. This was handled using class weights during training so the model does not ignore the minority classes.

## How to Run

**Install dependencies**

```
pip install -r requirements.txt
```

**Train the model**

Open SolarPanel_DefectDetection.ipynb and run all cells from top to bottom. The notebook will train the model and save it as solar_panel_model.h5 in the same folder. Training happens in two phases - first only the top classification layers are trained, then the last 30 layers of MobileNetV2 are fine-tuned at a lower learning rate.

**Run the web app**

Make sure solar_panel_model.h5 is in the same folder as app.py, then run:

```
cd SubmissionProject
streamlit run app.py
```

Open http://localhost:8501 in your browser and upload a solar panel image to get a prediction.

---

## Model Details

- Base model: MobileNetV2 pretrained on ImageNet
- Input size: 128 x 128
- Phase 1: Train top layers only, lr = 0.001, up to 30 epochs with early stopping
- Phase 2: Unfreeze last 30 layers, lr = 0.0001, up to 15 epochs
- Loss function: Categorical crossentropy
- Class imbalance handled with class weights
